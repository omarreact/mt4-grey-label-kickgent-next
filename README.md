# Kickgent — PinTheme Next.js → HTML → WordPress

Kickgent is the proof-of-concept project for **PinTheme by PINCODE IT**. GitHub remains the source of truth for theme code and supported design defaults. Development happens in Next.js; CI produces a standalone static HTML distribution and a native WordPress production theme. WordPress production does **not** require Next.js, Node.js, React hydration, or Next.js routing.

## Routes

The project exports 11 routes: `/`, `/mt4-grey-label/`, `/mt5-grey-label/`, `/turnkey-grey-label/`, `/forex-broker-crm/`, `/forex-broker-website/`, `/forex-liquidity-bridge/`, `/pamm-mam/`, `/how-to-start-forex-brokerage/`, `/scale-forex-brokerage/`, and `/about/`.

## PinTheme distributions

- Next.js development site: App Router source in `app/`, `components/`, and `content/`.
- Static HTML: generated by `next build` into `out/` using `output: "export"`.
- Native WordPress theme: `wordpress/kickgent-pintheme/`.
- WordPress companion plugin: `wordpress/pintheme-manager/`.
- Versioned compatibility manifest: `pintheme.manifest.json`.
- Shared tokens and compatibility registry: `pintheme/`.

The previous `wordpress/kickgent-fse/` and `wordpress/kickgent-github-sync/` folders are retained as legacy compatibility references, but the PinTheme build no longer packages them as the production distribution.

## WordPress editing model

The classic theme exposes **Appearance → PinTheme Settings** for global colors, container width, section spacing, logo sizing, header height, sticky behavior, navigation CTA, and footer text. Header/footer templates are global and WordPress menus/custom-logo APIs are supported. This avoids requiring Full Site Editing for routine branding and layout adjustments.

**PinTheme Manager** provides public-GitHub package validation, import preview, safe-by-default page synchronization, local-edit conflict detection, first-import navigation setup, update status, up to five content snapshots, and rollback of the latest content import. Existing locally edited pages are preserved unless an administrator explicitly chooses destructive replacement.

Private repository OAuth/GitHub App authentication, media-library mirroring, release installation, code editing, and full staging automation are later phases and are not claimed complete in this proof of concept.

## Commands

```bash
npm install
npm run audit:design
npm run validate
npm run build:pintheme
npm run export:html
npm run validate:pintheme
npm run generate:wordpress
npm run check
npm run test:ui
```

GitHub Actions builds and validates all three distributions, lints WordPress PHP, uploads ZIP artifacts, and synchronizes reviewed import metadata after `main` updates.
